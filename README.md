# nikori Futsal Timer v1.0.0

主にフットサルで3,4チームでひたすら対戦をする時の対戦表と時間管理に
特化した試合タイマーアプリ（Android）。
個サルとかで自分で使いたいので作りました。

笛や音声での進行アナウンス、連戦の対戦表、
2面同時タイマーに対応した、現場で使える試合運営タイマーです。

## 📥 インストール方法

1. 下の **Assets** から `nikori-futsal-timer-v1.0.0.apk` をダウンロード
2. Android端末でAPKをタップ
3. 「提供元不明のアプリ」のインストールを**許可**（初回のみ設定画面に誘導されます）
4. インストール後、「nikori Futsal Timer」を起動

> 動作環境: Android 7.0 以降を推奨 / iPhoneには非対応

## ✨ 主な機能

- ⏱ **試合タイマー** — ±1分・±10秒で時間設定、終了予定時刻ベースの正確な計時
- 🔔 **通知** — ハーフ / 〇分ごと / なし（試合中でも切替可能）＋ 30秒前通知
- 🔊 **音声案内** — 開始・ハーフ・インターバル・終了・カウントダウンごとに「笛 / 音声 / 両方 / なし」を選択
- 🗂 **連戦の対戦表** — 1面(2〜4チーム) / 2面(4〜7チーム)の総当たり表を自動生成、全画面で確認可能
- 👕 **チームカラー** — ビブスの色でチームを色分け（色の入れ替え・テーマごとに保存）
- 🏟 **2面デュアルタイマー** — コートA/Bを独立して開始・停止。時間は共通、通知はアクティブなコートのみ
- 🎨 **4テーマ** — ダーク / ライト / ポップ / サイバー（設定はテーマごとに保持）
- 🔈 **アラーム音量で再生** — 端末のアラーム音量で鳴るので、音楽などのメディア音量とは独立して調整可能
- 📱 **画面スリープ防止** — 計測中は画面が消えません

## 📝 補足

- タイマー音は**アラーム音量**で鳴ります。鳴らない場合は端末の「アラームの音量」を上げてください（マナーモード中でも鳴ります）。
- アプリを開いて使う前提です。バックグラウンド・画面オフ時の終了通知はAndroidのOS制約を受けます。
